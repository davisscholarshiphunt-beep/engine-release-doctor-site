# Engine Release Doctor Site

Public marketing and educational website for **Engine Release Doctor**.

## Current public offer

Engine Release Doctor is presently a **limited free beta manual Release Blocker Audit** for qualified Unreal Engine release failures. The site must not claim that automated diagnostics, automatic fixes, guaranteed repairs, or store approvals are available unless repository-verifiable evidence and the approved Offer of Record support those claims.

## Publication rules

Public content should:

1. Address a specific, evidenced Unreal release problem.
2. Provide useful standalone guidance.
3. Distinguish verified facts from hypotheses and troubleshooting tests.
4. Link to primary sources when making technical claims.
5. Use the current approved offer and one proportionate call to action.
6. Avoid duplicate or low-value publication.
7. Never expose customer data, credentials, private logs, internal business records, or source code from the private product repository.

## Structure

- `index.html` — landing page and beta application path
- `styles.css` — shared responsive design system
- `resources/` — public troubleshooting articles and resource index
